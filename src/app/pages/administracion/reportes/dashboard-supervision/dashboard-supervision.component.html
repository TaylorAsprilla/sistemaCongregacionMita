¿Cómo se calcula si una congregación requiere atención?

Las alertas incluyen solo las Congregaciones Ciudad. Una congregación aparece como Requiere atención cuando cumple al menos una de estas condiciones:

  • Informe pendiente: tiene obrero asignado y no ha registrado el informe del trimestre consultado.
  • Disminución significativa: un indicador bajó {{ rg.significativo }} % o más frente al periodo de comparación. Variación = (actual − anterior) ÷ anterior × 100. Solo se calcula si la congregación tiene informe en ambos periodos y el valor anterior es mayor que 0.
  • Tendencia de disminución: un indicador bajó en {{ rg.trimestresTendencia }} cambios trimestrales consecutivos (requieren datos de {{ rg.trimestresTendencia + 1 }} trimestres, dentro de los últimos {{ rg.trimestresHistorico }}). Un trimestre sin informe interrumpe la secuencia.
  • Asunto recurrente: el mismo asunto pendiente se reportó en {{ rg.trimestresAsuntoRecurrente }} trimestres consecutivos o más.

Indicadores evaluados: asistencia general a servicios, promedio de asistencia por servicio (general, martes, jueves y domingo), asistencia a consejeros, participación en vigilias, actividades espirituales, visitas a hogares y visitas pastorales totales.

Los incrementos de {{ rg.significativo }} % o más y las tendencias de crecimiento se muestran como Informativa. Entre {{ rg.moderado }} % y {{ rg.significativo }} % la variación se considera moderada y no genera alerta. Las alertas describen la información registrada; no califican a la congregación.
